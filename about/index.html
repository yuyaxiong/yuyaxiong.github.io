关于这里

我是余亚雄，欢迎来到我的个人笔记。

为什么记录

这里用于整理商业案例、经营分析与长期思考。写作的目标是把一件事情说明白：当时有哪些约束，做了什么选择，结果如何，又有哪些尚不能确定的地方。

如何阅读

文章会尽量标明数据来源、时间范围与口径，并把事实与个人判断分开。案例中的成功经验需要放回当时的条件理解，不能直接当作所有企业的通用答案。

内容与使用

本站发布原创中文分析。引用资料的权利属于原作者及出版者；本站不提供所引用商业案例的全文或完整译本。转载本站原创文章请先联系作者并保留来源链接。

更新与勘误

新文章会出现在首页和文章列表，也可通过 RSS 订阅。若发现事实或数字有误，可在 GitHub Issues 提交问题，注明文章和对应段落。

隐私

本站使用静态页面，无账户、评论表单或第三方访问统计脚本。搜索在浏览器本地完成。站点托管服务可能记录访问日志，详见 GitHub 隐私声明。
